# 桌面端 ↔ 纯 Web 端 功能对齐现状与后续计划（如实）

> 本文如实记录两端差异，避免过度宣称。核对方式：从桌面 Tauri 的命令注册表逐一比对 Go 后端实现。

## 一句话结论

**业务功能（数据模型与逻辑）已完整对齐**：桌面端 83 个命令 **100% 已在 Web 端路由**，核心域（任务/习惯/目标打卡/记账发薪/外债/知识库/搜索/仪表盘/快速记录/保险库/加密同步）全部落地并有测试。
**但存在若干「有意差异」和「已知差距」**，均列在下方，请按此预期使用。

命令覆盖核对：桌面 `#[tauri::command]` 共 83 个（另 `run_prepare_exit` 为内部辅助，非命令）→ Web 端全部有对应处理；无「桌面有、Web 完全未处理」的命令。

---

## 一、完全对齐（行为等价，已测试）

| 域 | 说明 |
|----|------|
| 任务 Tasks | 增删改查、今日、优先级、到期提醒任务生成 |
| 习惯/目标打卡 Goals | plan/habit/checkin 三类；里程碑、每日打卡、进度公式、连续天数、计划提醒（均按产品 Spec） |
| 记账 Finance | 快速记账解析、发薪周期结余/有效结余/还债后可支配、周期存档快照、分类/图表 |
| 外债 Debt | 等额本息 / 先息后本摊还、还款、剩余本金校准、还款提醒 |
| 知识库 Knowledge | Markdown 文件 CRUD、分类、树 |
| 搜索 Search | SQLite FTS5（unicode61），行为与桌面一致 |
| 仪表盘/偏好/快速记录/快速笔记 | 全部一致 |
| 保险库 Vault | 初始化/解锁/锁定/登出/改主密码/状态；加密参数与桌面一致（Argon2id + AES-256-GCM），**同步包可与桌面互通** |
| 加密同步 Sync | GitHub / Gitee 私有仓 加密包 拉/推；远端增删改、测试连接、Git 配置迁移（文本） |

> 加密同步已通过「双设备 + 不同主密码 + 配置迁移」的自动化测试；备份下载/上传、改密码保留 PAT 等均有测试或实机验证。

## 二、有意差异（Web 更合理，功能等价但方式不同）

| 项 | 桌面 | Web | 说明 |
|----|------|-----|------|
| 应用内更新 | Tauri updater 下载安装 | **移除** | Web 刷新页面即最新，无需更新器（`fetch_update_manifest` 返回空） |
| 备份 | 写本地文件路径 | 浏览器**下载 / 上传** ZIP | 功能等价；`export_backup/import_backup` 命令引导到设置页按钮，实际走 `/api/backup/*` |
| Git 配置迁移 | 文件路径 或 文本 | **文本复制/粘贴** | 文件路径变体引导到文本；文本变体完全实现，手机端本就用文本 |
| 系统通知 | 原生系统通知 | **Web Notifications API** | 提醒逻辑一致；投递依赖浏览器授权，iOS Safari 需「添加到主屏」后才较可靠 |
| 窗口边框/托盘/单实例 | 原生窗口 | 不适用 | Web 无此概念 |
| 打包分发 | 桌面安装包 / Android APK | 浏览器访问（可「添加到主屏」当 App） | 分发方式不同，非逻辑差异 |

---

## 三、有意不做（威胁模型不同，如实告知）

- **记住密码 / 自动解锁**：桌面会记住主密码，启动免输；**Web 不持久化主密码**，每次打开/刷新都需输入主密码（`vault_try_auto_unlock` 在 Web 为空操作）。这是刻意的安全取舍，公网暴露时尤为重要。

---

## 四、已知差距（Web < 桌面，待定）

| 差距 | 现状 | 影响 | 计划 |
|------|------|------|------|
| **同步冲突合并** | 两端均为「先拉后推、后写覆盖」，无真正合并 | 两端一致；多设备并发编辑可能覆盖 | 见后续 P2（加冲突提示/时间戳保护） |
| **iOS 通知** | Web Notifications 在 iOS 需「添加到主屏」为 PWA 后才较可靠 | iOS 浏览器通知受限（非 PWA 时） | 已提供 PWA 安装（缓解）；进一步说明见文档 |

> ✅ 本轮已补齐：**多档案（每个主密码 = 一个独立空间；解锁自动匹配空间）**；**AtomGit** 已作为 provider 删除（GitHub/Gitee 保留）；**PWA**（manifest + Service Worker + 图标，可「添加到主屏」当 App、离线打开应用外壳）。

## 五、后续计划（明确、分优先级）

### P1 · 可用性打磨
- [x] **PWA 化**：`manifest.webmanifest` + Service Worker（Workbox，`/api` 不缓存）+ 图标 + iOS `apple-touch-icon`；可「添加到主屏」当 App、离线打开外壳。
- [x] **多档案**：已实现。每个主密码对应一个独立加密空间（`<root>/<id>/`）；解锁时自动匹配空间，「用新密码创建独立空间」可用；切换空间会先封库再打开另一空间。
- [ ] 可选「**本会话记住**」（仅内存，不落盘），减少频繁输密码，同时不违背威胁模型。

### P2 · 同步增强
- [ ] 同步**冲突提示**：推送前比对远端 `contentHash`/时间戳，冲突时提示而非静默覆盖。
- [ ] 同步**失败重试 / 断点**与更细的错误反馈。
- (AtomGit provider 已按需求删除，不再计划)

### P3 · 公网加固（已具雏形，可继续）
- [ ] **内置 ACME**（Let's Encrypt 自动签发/续期），直连公网也能有效证书、免自签警告。
- [ ] 可选 **HTTP Basic Auth** / 允许来源细化 / 可选 per-IP 限流。
- [ ] `phddns` 开机自启 systemd 示例（花生壳客户端）。

### P4 · 性能/树莓派（可选）
- [ ] 前端按需分包，降低首屏体积（当前 gzip≈136KB，够用）。
- [ ] 针对低配树莓派的运行参数建议。

### 明确不做（范围外）
- 零知识（服务端解锁期间可见明文，与桌面一致的模型）。
- 多用户 SaaS。
- 与正在运行的桌面进程共享同一解锁会话。

## 六、如何自行核对

```bash
# 桌面命令（从含 src-tauri 的历史提交）
git show '<含src-tauri的提交>^:src-tauri/src/commands/mod.rs' \
  | grep -A1 '#\[tauri::command\]' | grep -oE 'pub fn [a-z_]+' | sed 's/pub fn //' | sort -u
# Web 端已处理命令
grep -oE 'case "[a-z_]+"' server/internal/core/rpc.go server/internal/httpapi/server.go \
  | grep -oE '"[a-z_]+"' | tr -d '"' | sort -u
```
