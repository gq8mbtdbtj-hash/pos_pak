# 电脑配置导出 → 手机导入（操作手册）

配置包含：**远端 URL、分支、用户名、PAT、同步密钥**（AES 加密）。  
**登录码不会导出**；手机可用自己的登录码。跨端解包靠配置里的同步密钥，与两端登录码是否相同无关。  
传输密码只保护这一次拷贝的配置文件，可与登录码不同。

> 注意：必须在 **已解锁** 的 Personal OS 里操作。

---

## 一、电脑端：先把数据推上远端

1. 打开 **Personal OS（桌面）** → 解锁  
2. 进入 **设置** → 确认已有 Git 配置并设为默认  
3. 点 **立即推送**（或先在「配置新建」里保存远端与 PAT 再测试连接）  
   - 仓库里应出现 `sync/manifest.json` 与 `sync/latest.posenc`

没有这一步，手机即使导入了配置也拉不到内容。

---

## 二、电脑端：导出配置（二选一）

### 方式 A：复制到剪贴板（推荐发给手机）

1. **设置** → **配置同步**  
2. **传输密码** 填一个你记得住的短密码（例：`xfer-2026`）  
3. 点 **复制加密配置**  
4. 文本框会出现一长串 JSON；同时已进剪贴板  
5. 用微信 / 便签 / 邮件发给自己的手机（勿发到公开群）

### 方式 B：导出到文件

1. **传输密码** 同上  
2. **文件路径** 建议：

```text
C:\Users\ikjm\Desktop\personal-os-git.posgit
```

3. 点 **导出到文件**  
4. 把该文件拷到手机（数据线 / 云盘 / 微信文件）

---

## 三、手机端：导入并同步

1. 安装并打开 **Personal OS（Android）**，用手机登录码解锁  
2. **设置** → **配置同步**  
3. **传输密码** = 电脑导出时用的同一个  
4. 把电脑发来的 JSON **整段粘贴**进文本框  
5. 点 **导入配置**  
6. 回到设置首页确认远端列表，再点 **立即拉取**

导入会 **覆盖** 当前档案里的 Git 远端与 PAT，不会改登录码。

---

## 四、日常同步

| 场景 | 操作 |
|------|------|
| 电脑改完要给手机 | 电脑 **立即推送** → 手机 **立即拉取** |
| 手机改完要给电脑 | 手机 **立即推送** → 电脑 **立即拉取** |
| 关应用 | 不会自动推送，需手动推 |

---

## 五、常见问题

| 现象 | 处理 |
|------|------|
| 解密失败 | 传输密码不一致或 JSON 被截断，重新复制整段 |
| 连接/拉取 401、403 | PAT 权限不足（GitHub 需 `repo`；Gitee 需私有仓读写） |
| 拉取 empty | 电脑尚未成功 **立即推送** |
| AtomGit | 暂不支持 HTTPS Contents，请改用 GitHub/Gitee |
