# 产品 Spec：发薪结余 + 计划/打卡统一

> 真源文件。实现 / Review / 自测以本文为准。行为与 Spec 不符时优先改代码；改 Spec 须用户确认。

## 1. 记账 · 结余与筛选

| 指标 | 是否跟随日/周/月筛选 | 计算口径 |
|------|----------------------|----------|
| 收入 | 是 | 筛选区间内 `type=income` 合计 |
| 支出 | 是 | 筛选区间内 `type=expense` 合计 |
| 图表 | 是 | 同筛选区间分桶 |
| **本期账单净额** | **否** | 当前发薪周期内 收入 − 支出 |
| **期初结余** | **否** | 上一发薪周期已确认存档 `snapshot.net`；无则空 |
| **有效结余** | **否** | 有期初：`opening + 本期账单净额`；无期初：等于本期账单净额并标「未含上期」 |
| **本期应还** | **否** | 当前发薪窗口内、未付清分期金额合计 |
| **还债后可支配** | **否** | `有效结余 − 本期应还`（&lt;0 标吃紧） |

首页 / 记账英雄主数字为 **有效结余**；账单净额与日历月盈亏为次要。

### 1.1 发薪日

- 设置页可配置，取值 **1–28**（含），默认 **1**。
- 存于档案内 `app_prefs.json`；**随 Git 同步包 / 本地备份一起传输**（与 DB、知识库同包）。

### 1.2 发薪周期算法

设发薪日为 `D`，「今天」为本地日期 `T`：

- 若 `T.day >= D`：本期 `[本月 D 日 00:00, 下月 D 日 00:00)`
- 否则：本期 `[上月 D 日 00:00, 本月 D 日 00:00)`

UI 展示周期文案，例如 `结余 · 3/15–4/14`。

### 1.3 非目标

- 有效结余 / 期初 / 本期账单净额 / 还债后可支配 **不得**因切换日/周/月而改变（未改发薪日、未跨周期边界时）。
- 不做完整分类预算（Ready to Assign）；到期日风险仍按 §5.1，钱的压力用「还债后可支配」单独结论。

### 1.4 周期结束 · 确认存档

- 本地日跨进**新发薪周期**后，对**上一周期**弹出提醒；展示账单合计（收入 − 支出），**结余数字可修正**后再存档。
- 写入 `pay_period_snapshots`：`period_start` / `period_end`、当时账单收入/支出、**用户确认（可修正）的结余**、`confirmed_at`、可选备注。同一 `period_start` 只存一条，**已存档仍可再改**。
- 已确认的上期结余即为**下期期初**，参与有效结余与还债后可支配；修正存档后上述数字立刻变。
- 未确认：首页与记账顶栏标明「上期结余待确认」，点开可修正；「稍后」只关掉本次弹窗，顶栏仍可打开；英雄为「仅账单净额」。
- 日历月盈亏为次要。

## 2. 养成 · 分类

| 类型 | 产品名 | 说明 |
|------|--------|------|
| `plan` | **计划** | 原「普通目标」。里程碑勾选算进度；**无图表**；可设目标截止日。 |
| `habit` | **习惯培养** | 原独立习惯。每日是否打卡（可有备注）；**66 天连续**算进度；无起止实测折线。 |
| `checkin` | **目标打卡** | 必须有开始值、目标值；每日填实测值；折线 + 目标虚线 + 差距。 |

- 养成页筛选：**计划 | 习惯 | 打卡**（「打卡」仅指目标打卡）。
- 旧 `habits` / `habit_records` 须迁移为 `habit`（见 §6）。
- 现有 `kind=normal` 视为 `plan`；曾误迁为 `checkin` 且 `start=0,target=66,unit=天` 的应视为 `habit`。

## 3. 进度公式

### 3.1 目标打卡（`checkin`）

- 创建必填：**目标值** `targetValue`、可选 `unit`、可选截止日 `targetDate`。
- **起点**不在创建时填写：以**第一次打卡**的实测 `value` 登记为 `startValue`（如减重目标 76kg，首次打卡 82.8kg → 起点 82.8）。
- 打卡存实测 **`value`**（必填），可选备注；**时间精确到小时**（分钟不计）；**同一天允许多次**打卡。
- `current` = 最近一次打卡的 `value`；尚无打卡时不伪造 0，进度/差距为空态。
- `progress% = clamp( (current - start) / (target - start) * 100 , 0, 100 )`（需已有起点）。
- **差距**（沿 start→target 方向）：  
  - 若 `target > start`（递增）：还差 = `target - current`（负值表示超出）  
  - 若 `target < start`（递减）：还差 = `current - target`（负值表示超出）  
  - 文案：还差 / 超出 / 已达目标；相对上次打卡再标「更近 / 更远」。
- **图表时间轴**：X = 首次打卡时刻（小时）→ 截止日结束（无截止日则用「现在」或最近打卡时刻，取较晚者）；Y = 实测值；虚线 = 目标值；起点线 = 首次打卡值。**同日多次时，图表与列表只展示当天最晚一次**；Y 轴仅稀疏刻度（勿按每个数据点贴标签）。
- 与习惯 66 天无关；禁止用 0/0 冒充已达标。

### 3.2 习惯培养（`habit`）

- 创建无需起止值（内部固定 `start=0,target=66,unit=天` 仅作养成天数）。
- 每日打卡为**出勤**：有记录即算当日完成（`value` 可存 1）；备注可选。
- `progress% = clamp( streak / 66 * 100 , 0, 100 )`。
- **不做**起止值折线图；列表展示连续天数与 66 天进度条。

### 3.3 计划

- `progress% = done_milestones / total_milestones * 100`（无里程碑时进度为 0）。
- 里程碑：**必填截止日** `dueDate`；新建为未完成；勾选判定完成；列表按截止日排序。

## 4. 习惯 · 66 天连续

- 漏 **1** 天可延续连续计数。
- **连续 2 天**未打卡则中断。
- 「已养成」：有效连续打卡天数 ≥ **66**。

目标打卡不以 66 天为完成条件；以数值 `progress >= 100` 为达标。

---

## 5. 任务提醒（计划 / 还款）

任务来源只有两类：

1. **到期提醒**：用计划 `targetDate` 或还款分期 `dueDate` 与**当天本地日期**对比后生成；**不**预写 d-3 / d-1 / d0 三条任务。
2. **主动创建**：用户在任务页明确添加的任务，直接进入任务清单（按优先级分栏）。

### 5.1 风险分级（弹窗 / 系统通知）

| 当天距截止日 | 风险 | 任务优先级 | 弹窗与通知 |
|--------------|------|------------|------------|
| 正好 **3** 天 | 低 | `low` | 是 |
| **≤ 1** 天（含当天、逾期） | 高 | `high` | 是 |
| 其它（如 2 天、4–31 天） | — | `low` | 否（仍可出现在到期列表） |

### 5.2 任务与标签

- 每个进行中且有截止日的计划至多 **1** 条：`plan-remind:{goalId}` + `plan-due:{YYYY-MM-DD}` + 「计划提醒」。
- 每笔待还分期至多 **1** 条：`debt-remind:{installmentId}` + `debt-due:{date}` + 「还款提醒」。
- 约一个月内的到期项写入任务表；解锁后走同一 `refreshLocalReminders` 通道。
- UI：主动任务在左侧优先级栏；到期提醒在右侧「近 7 天 / 近 1 月」（逾期计入近 7 天）。

### 5.3 Glance 落点

风险分级与弹窗相同（§5.1）。除弹窗与任务页外须出现在：

- **首页**：一条最高风险结论（高优先于低；否则「近 7 天无到期」）。
- **记账顶栏**：结余旁外债/计划风险芯片，可跳转外债或任务。
- **外债「近期应还」行**：低 / 高标签。

---

## 6. 习惯表 → `habit` 迁移

- 每条启用习惯 → 一个 `kind=habit` 目标。
- 历史有完成记录的日期 → `goal_checkins`（出勤）。
- 进度按 §3.2 与 §4。

## 7. UI 要点

- 记账：结余文案标明发薪周期；收支带日/周/月标签。
- 养成：筛选 **计划 | 习惯 | 打卡**。
- **目标打卡**详情：折线图（实线=打卡值，虚线水平=目标值）+ 差距。
- **习惯**详情：连续/66、进度条；无折线。桌面可加出勤热力；计划详情仍**不渲染**进度折线图。
- **手机**：首页三结论（有效结余、最高到期风险、今日养成）+ 底栏快记；习惯一键出勤；目标打卡须填实测（进养成页）。记账图、外债分期编辑折到「明细/管理」。
- **桌面**：同一结论做页眉；下面是明细、分类图、外债计划、打卡图。

## 8. 验收清单

- [ ] 改日/周/月：收入支出变，结余不变（未跨发薪边界）。
- [ ] 改发薪日：结余区间文案与数额更新。
- [ ] 习惯与目标打卡分开展示/创建；旧习惯为 `habit` 且可续。
- [ ] 目标打卡：创建填目标值+单位+截止日；首次打卡登记起点；时间精确到小时且同日可多次；图表 X 为首打卡→截止；无数据不显示假达标。
- [ ] 习惯只需每日出勤；有 66 天连续规则。
- [ ] 计划无图；里程碑必填截止日并勾选完成；计划/还款按截止日与当天对比提醒（正好 3 天低风险，≤1 天高风险）；主动任务直接进清单。
- [ ] 跨发薪周期后弹出上期结余，可修正数字后存档；已存档仍可改；确认后作为下期期初；首页英雄为**有效结余**；还款风险出现在首页/记账/外债近期应还。
- [ ] 改上期存档净额 → 本期有效结余与还债后可支配同步变；本期内未还分期计入本期应还。
- [ ] 首页可一键习惯出勤；目标打卡不造假 0。
- [ ] 仓库存在本 Spec 与 `.cursor/skills/spec-debug-loop/`。
