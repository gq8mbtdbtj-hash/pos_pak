# 产品 Spec：发薪结余 + 计划/打卡统一

> 真源文件。实现 / Review / 自测以本文为准。行为与 Spec 不符时优先改代码；改 Spec 须用户确认。

## 1. 记账 · 结余与筛选

| 指标 | 是否跟随日/周/月筛选 | 计算口径 |
|------|----------------------|----------|
| 收入 | 是 | 筛选区间内 `type=income` 合计 |
| 支出 | 是 | 筛选区间内 `type=expense` 合计 |
| 图表 | 是 | 同筛选区间分桶 |
| **结余** | **否** | 仅当前**发薪周期**内 收入 − 支出 |

### 1.1 发薪日

- 设置页可配置，取值 **1–28**（含），默认 **1**。
- 存于档案内 `app_prefs.json`；**随 Git 同步包 / 本地备份一起传输**（与 DB、知识库同包）。

### 1.2 发薪周期算法

设发薪日为 `D`，「今天」为本地日期 `T`：

- 若 `T.day >= D`：本期 `[本月 D 日 00:00, 下月 D 日 00:00)`
- 否则：本期 `[上月 D 日 00:00, 本月 D 日 00:00)`

UI 展示周期文案，例如 `结余 · 3/15–4/14`。

### 1.3 非目标

- 结余不得因切换日/周/月而改变（未改发薪日、未跨周期边界时）。

## 2. 养成 · 分类

| 类型 | 产品名 | 说明 |
|------|--------|------|
| `plan` | **计划** | 原「普通目标」。里程碑勾选算进度；**无图表**；可设目标截止日。 |
| `habit` | **习惯培养** | 原独立习惯。每日是否打卡（可有备注）；**66 天连续**算进度；无起止实测折线。 |
| `checkin` | **目标打卡** | 必须有开始值、目标值；每日填实测值；折线 + 目标虚线 + 差距。 |

- 养成页筛选：**计划 | 习惯 | 打卡**（「打卡」仅指目标打卡）。
- 旧 `habits` / `habit_records` 须迁移为 `habit`（见 §6）。
- 现有 `kind=normal` 视为 `plan`；曾误迁为 `checkin` 且 `start=0,target=66,unit=天` 的应视为 `habit`。

## 3. 进度公式

### 3.1 目标打卡（`checkin`）

- 创建必填：**目标值** `targetValue`、可选 `unit`、可选截止日 `targetDate`。
- **起点**不在创建时填写：以**第一次打卡**的实测 `value` 登记为 `startValue`（如减重目标 76kg，首次打卡 82.8kg → 起点 82.8）。
- 每日打卡存实测 **`value`**（必填），可选备注。
- `current` = 最近一次打卡的 `value`；尚无打卡时不伪造 0，进度/差距为空态。
- `progress% = clamp( (current - start) / (target - start) * 100 , 0, 100 )`（需已有起点）。
- **差距**（沿 start→target 方向）：  
  - 若 `target > start`（递增）：还差 = `target - current`（负值表示超出）  
  - 若 `target < start`（递减）：还差 = `current - target`（负值表示超出）  
  - 文案：还差 / 超出 / 已达目标；相对上次打卡再标「更近 / 更远」。
- **图表时间轴**：X = 首次打卡日 → 截止日（无截止日则用「今天」或最近打卡日，取较晚者）；Y = 实测值；虚线 = 目标值；起点线 = 首次打卡值。
- 与习惯 66 天无关；禁止用 0/0 冒充已达标。

### 3.2 习惯培养（`habit`）

- 创建无需起止值（内部固定 `start=0,target=66,unit=天` 仅作养成天数）。
- 每日打卡为**出勤**：有记录即算当日完成（`value` 可存 1）；备注可选。
- `progress% = clamp( streak / 66 * 100 , 0, 100 )`。
- **不做**起止值折线图；列表展示连续天数与 66 天进度条。

### 3.3 计划

- `progress% = done_milestones / total_milestones * 100`（无里程碑时进度为 0）。
- 里程碑：**无截止时间**；新建为未完成；勾选判定完成。

---

## 4. 习惯 · 66 天连续

- 漏 **1** 天可延续连续计数。
- **连续 2 天**未打卡则中断。
- 「已养成」：有效连续打卡天数 ≥ **66**。

目标打卡不以 66 天为完成条件；以数值 `progress >= 100` 为达标。

---

## 5. 计划 · 截止日期提醒

- 计划有 `targetDate` 时，在截止前 **d-3 / d-1 / d0** 触发本地任务提醒。
- 任务标签约定：`plan-remind:{goalId}:{d3|d1|d0}`（及可读标签如「计划提醒」）。
- 解锁后走与外债提醒相同的 `refreshLocalReminders` 通道。

---

## 6. 习惯表 → `habit` 迁移

- 每条启用习惯 → 一个 `kind=habit` 目标。
- 历史有完成记录的日期 → `goal_checkins`（出勤）。
- 进度按 §3.2 与 §4。

---

## 7. UI 要点

- 记账：结余文案标明发薪周期；收支带日/周/月标签。
- 养成：筛选 **计划 | 习惯 | 打卡**。
- **目标打卡**详情：折线图（实线=打卡值，虚线水平=目标值）+ 差距。
- **习惯**详情：连续/66、进度条；无折线。
- 计划详情：**不渲染**进度折线图。

---

## 8. 验收清单

- [ ] 改日/周/月：收入支出变，结余不变（未跨发薪边界）。
- [ ] 改发薪日：结余区间文案与数额更新。
- [ ] 习惯与目标打卡分开展示/创建；旧习惯为 `habit` 且可续。
- [ ] 目标打卡：创建填目标值+单位+截止日；首次打卡登记起点；图表 X 为首打卡→截止；无数据不显示假达标。
- [ ] 习惯只需每日出勤；有 66 天连续规则。
- [ ] 计划无图；有里程碑勾选；有截止日时 d-3/d-1/d0 提醒。
- [ ] 仓库存在本 Spec 与 `.cursor/skills/spec-debug-loop/`。
